# RADAR2026 Data Generation Guide

This document describes the synthetic radar pulse dataset generation pipeline for RADAR2026.

## 1. Project Data Structure

Generated data is stored outside the source-code directory:

```text
RADAR2026/
├── src/
│   └── data/
│       ├── config.py
│       ├── pri_generators.py
│       ├── emitter.py
│       ├── mixer.py
│       ├── dm_builder.py
│       ├── dataset_writer.py
│       └── inspect_dataset.py
│
├── data/
│   ├── train/
│   ├── val/
│   ├── test/
│   └── controlled_tests/
```

src/data/ contains dataset generation code.

data/ contains generated .npz files.

Do not store generated .npz files inside src/data/.

## 2. Dataset Design

Each generated sample contains a fixed-length mixed pulse sequence.

Default settings:

N = 256 pulses
K = 32 lag orders
model_input shape = [2, 256, 32]
affinity_mask shape = [256, 32]

The model input contains two channels:

channel 0: normalized Difference Matrix
channel 1: valid DM mask

The main training label is the binary same-emitter affinity mask:

affinity_mask[n, k] = 1

if and only if pulse n and pulse n - lag belong to the same real emitter.

Noise and padding labels are 0 and never form positive affinity relations.

## 3. Standard Dataset

The full standard dataset contains 50,000 samples:

train: 40,000
val: 5,000
test: 5,000

The standard dataset is generated by:

python -m src.data.dataset_writer --mode full

Before generating the full dataset, always run the small debug version first:

python -m src.data.dataset_writer --mode small

Then inspect:

python -m src.data.inspect_dataset --split train
python -m src.data.inspect_dataset --split val
python -m src.data.inspect_dataset --split test

## 4. Controlled Test Dataset

Controlled test slices are used for paper experiments.

They include:

emitters_2
emitters_4
emitters_6

pulse_loss_0.0
pulse_loss_0.1
pulse_loss_0.2
pulse_loss_0.3

noise_lambda_0.2
noise_lambda_0.5
noise_lambda_0.8
noise_lambda_1.0

ablation_4_emitters

Generate controlled tests:

python -m src.data.dataset_writer --mode controlled

Inspect controlled tests:

python -m src.data.inspect_dataset --split controlled

For quick debugging, temporarily set this value in src/data/config.py:

samples_per_controlled_setting: int = 20

After debugging, restore it to:

samples_per_controlled_setting: int = 1_000

## 5. Individual Module Checks

Run from the RADAR2026 root directory:

python -m src.data.config
python -m src.data.pri_generators
python -m src.data.emitter
python -m src.data.mixer
python -m src.data.dm_builder

## 6. Expected Sample Fields

Each .npz sample should contain:

model_input: (2, 256, 32), float32
affinity_mask: (256, 32), float32
valid_dm_mask: (256, 32), bool
difference_matrix: (256, 32), float32
normalized_dm: (256, 32), float32
toa_us: (256,), float32
pulse_labels: (256,), int64
valid_pulse_mask: (256,), bool
metadata_json: JSON string

## 7. Sanity Check Criteria

A generated dataset is considered valid if:

Passed files: all
Failed files: 0
TOA increasing: True
Label range: 0 to 2~6
valid_dm_ratio: approximately 0.9355 when all 256 pulses are valid
affinity_positive_ratio: greater than 0 but not too large
num_emitters: between 2 and 6 for standard data
PRI types: constant / staggered / jittered / sliding all appear
pulse_loss_rate: within configured range
noise_lambda: within configured range

## 8. Important Notes
Always run commands from the RADAR2026 root directory.
Use package mode:
python -m src.data.dataset_writer --mode small

Do not use:

python src/data/dataset_writer.py --mode small
Generated data should be saved under:
RADAR2026/data/

not under:

RADAR2026/src/data/data/

Do not generate the full 50,000-sample dataset until small and controlled tests both pass.
